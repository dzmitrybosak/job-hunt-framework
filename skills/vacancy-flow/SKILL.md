# vacancy-flow — флоу 1 Job Hunt

На входе — **одно из**: ссылка на вакансию, **текст JD + название компании**, или оба сразу. Если не дано ни того ни другого — спроси коротко, что прислать (текст предпочтительнее ссылки). Не требуй URL, если пользователь дал JD текстом.

1. Найди в воркспейсе фреймворк (`job-hunt/` или `job-hunt-framework/`), прочитай `prompts/_common.md` (включая «Веб: оркестрация research и экономия токенов»).
2. Шаг 1 — `prompts/vacancy-intake.md`: URL и/или paste → `vacancy.md` + `INDEX.md`. При paste **не открывай веб ради JD**.
3. **Гейт локации/формата** (`prompts/vacancy-intake.md`): если 100% подтверждено, что нужна страна работодателя / компания не работает с Беларусью / роль onsite-hybrid в стране работодателя – **стоп**: «роль не подходит», статус `closed` в `INDEX.md`, пакет и HTML **не генерировать**.
4. Выполни шаги флоу 1 из `AGENTS.md`: company-research → gap-analysis → gap-close → tailor-resume → find-people → message-drafts → cover-letter (процедуры — в `prompts/`). Веб — только по правилам экономии токенов. **HTML на этом этапе не собирать и не открывать.**
5. **Только когда весь контент готов и больше правок не будет** – собери единый HTML (последний шаг флоу): `vacancies/<slug>/content.json` + `python3 tools/build-report.py vacancies/<slug>` (шаблон не читать, HTML руками не писать), открой `index.html` в браузере (`open`). После сборки контент не менять; если правка нужна – поправить файл, пересобрать и снова открыть HTML.
6. В чат — только краткий итог: Match %, 2–3 строки «что внутри», путь к файлу.

Язык текстов — по `prompts/output-language.md`; неясен — один вопрос пользователю.
