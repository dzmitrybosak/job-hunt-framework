# Prompt: tailored CV summary (3 строки)

## Как выполняем в job-hunt

Подстановки: см. `_common.md`. Достижения с цифрами — строго из `profile/achievements.md`.

**Вход:** `vacancy.md`, Summary из `profile/master-cv-{ru|en}.md`, `profile/achievements.md`
**Выход:** Summary-блок в `resume-adapted.md` (в флоу 1); по отдельному запросу — просто текст в чат
**Режим:** A (по JD). В режиме B (флоу 2): ключевые слова из `target-role.md` + домен компании, строка «что ищу» — network-формулировка (интерес к команде/продукту), остальные правила те же.

## Шаги

1. Собрать ключевые слова JD: стек, домен, ключевые обязанности. Отметить, какие из них правдиво относятся к моему опыту.
2. Отобрать **2 конкретных achievements с цифрами** из банка — максимально близких к JD.
3. Написать **ровно 3 строки**:
   - строки 1–2: кто я + ключевые слова + 2 achievements с цифрами;
   - строка 3: что ищу (под эту роль и компанию).
4. Проверка перед выдачей:
   - покрытие **75–80% ключевых слов JD**, естественное вхождение (не stuffing: не больше 2 терминов подряд из списка);
   - ровно 2 achievements, оба с цифрами;
   - ни одного запрещённого слова (проверить по списку);
   - тон: confident, не аррогантный; нет «excited», «passionate»-семейства и прочих клише.

## Правила

- Правдивость важнее покрытия keywords: незамкнутые слова не впихивать (факты — `_common.md`).
- Запрещённые слова (и синонимы по духу): passionate, results-driven, team player, detail-oriented, open to opportunities, motivated, hard-working.
- Ровно 3 строки — не 4, не 2.
