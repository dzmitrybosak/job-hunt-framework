# Prompt: gap-анализ и % соответствия

**Вход:**
- Режим A (флоу 1): `vacancy.md` (JD) + `data/profile/master-cv-{ru|en}.md` + `data/profile/achievements.md` + `data/profile/experience-insights/` (+ точечно `data/profile/self-interview.md` по номеру вопроса)
- Режим B (флоу 2, нет вакансии): `data/profile/target-role.md` + `data/profile/master-cv-{ru|en}.md` + `data/profile/achievements.md` + `data/profile/experience-insights/` + `company.md`

**Выход:** `gap-analysis.md` в папке вакансии/компании.

## Шаги

0. **Гейт локации/формата** (`vacancy-intake.md`): если он уже сработал (100% onsite в стране работодателя / компания не работает с BY / onsite-hybrid в стране работодателя) – Match % не считать, пакет не генерировать; роль не подходит.
1. Собрать требования:
   - **Режим A:** из JD — must-have, nice-to-have, боли работодателя, ATS-ключевые слова.
   - **Режим B:** 6–8 типичных must-have для моей роли из `target-role.md` (стек + уровень) и 3–5 nice-to-have; явно пометить, что это профильные требования, а не конкретный JD.
2. Сопоставить каждое требование с master-cv, achievements и `experience-insights/`. Статус:
   - ✅ **full** — покрыто; указать чем именно и источник: `CV` / `банк` / `интервью В<N>`
   - ⚠️ **partial** — косвенно / частично (что подсветить)
   - ❌ **gap** — нет в истории
   Факт из интервью считается покрытием только если он подтверждён источником и не противоречит CV. Формулировку факта не усиливать: «участвовал» остаётся участием, «использовал» – использованием.
2a. Для каждого ⚠️/❌ проверить `experience-insights/gaps/bridges.md`: есть ли готовый мост из смежного опыта. Если да – указать его в «Что подсветить» / «Гэпы и что с ними делать».

## Рубрика Match % (считать, не «на глаз»)

- Каждый пункт: full = 1.0, partial = 0.5, gap = 0.0
- `score_must` = среднее по must-have, `score_nice` = среднее по nice-to-have (нет nice-to-have → score_nice = score_must)
- **Match % = round((0.7 × score_must + 0.3 × score_nice) × 100)**
- Шкала вердикта: **≥80 strong fit** · **60–79 good fit** · **40–59 stretch** · **<40 weak fit**

## Формат `gap-analysis.md`

См. также продолжение: `gap-close.md` — топ-3 пробела с закрытием опытом и готовыми bullets для CV.

```md
# Gap analysis — <Company> / <Role>
Дата:
Режим: A (по JD) | B (профильный, JD нет)
Ссылка: ...

## Match: NN% — <strong|good|stretch|weak> fit
Расчёт: must X.X × 0.7 + nice X.X × 0.3
<один абзац: главные причины оценки и главное действие>

## Must-have
| Требование | Статус | Что использовать (источник) |

## Nice-to-have
| Требование | Статус | Комментарий |

## Гэпы и что с ними делать
- Гэп 1 → (компенсировать чем / не подсвечивать / быстро подтянуть)

## Что подсветить
```

## Правила

- ❌ — нормально; честность важнее красивого совпадения (факты — `_common.md`).
- Новые факты запрещены; интервью даёт глубину и цифры, но не отменяет CV. Смысл факта не искажать – только формулировка.
- В режиме B в заголовке отчёта всегда писать, что скор профильный.
