# Prompt: адаптированное резюме

**Вход:** `vacancy.md` + `gap-analysis.md` (режим A) или `company.md` + `target-role.md` + `gap-analysis.md` режим B (флоу 2), `profile/master-cv-{ru|en}.md`, `profile/achievements.md`.
**Выход:** `resume-adapted.md` в папке вакансии/компании.

## Шаги

1. Взять из gap-analysis «что подсветить» и гэпы.
2. Переписать **только** эти блоки (остальное из master-cv не трогать):
   - В режиме B акценты — под домен/продукт компании и типичные требования роли (JD нет); в шапке файла указать `Режим: B (профильный, без JD)`.
   - **Summary** — строго по промпту `tailored-summary.md`: ровно 3 строки, 75–80% ключевых слов JD без stuffing, 2 achievements с цифрами, финальная строка «что ищу»; запрещённые слова и тон — см. промпт.
   - **Key achievements** — **полностью готовый список для вставки в резюме** (не выборка 3–5 bullets). Структура — как в CV, по проектам: `### <Компания> – <Роль> (<даты>)` → `#### <Проект> (<даты>)` → bullets. Включить все достижения из банка и Experience, которые идут в это резюме (по проектам, без схлопывания в плоский список). Формулировки bullets брать **как есть из банка** (`profile/achievements.md`) или из Experience; переписывать **только** если это нужно для адаптации под вакансию (лексика JD, язык резюме, убрать нерелевантный акцент) – не «для разнообразия». Факты и цифры не менять. Формат bullet — по `achievement-bullets.md`: `[action verb] + [scope/scale] + [result with number] + [tool/method]`, factual-тон, без successfully/efficiently/effectively. Блок должен открываться кнопкой Copy и вставляться в резюме без доработок.
   - **Skills order** — переставить по приоритету JD (добавлять навыки, которых нет в master-cv, нельзя).
3. Если JD просит конкретный формат (длина, секции, язык) — соблюдать.

## Формат `resume-adapted.md`

```md
# Adapted resume — <Company> / <Role>
Дата:
Язык: en

## Summary
...

## Key achievements

### <Компания> – <Роль> (<даты>)

#### <Проект> (<даты>)

- <bullet из банка / Experience, без лишнего переписывания>
- ...

#### <Ещё проект> (<даты>)

- ...

## Skills (порядок под вакансию)
...

## Что изменилось vs master-cv
- Summary: ...
- Achievements: включены A1–A5 и bullets из Experience по проектам X/Y; формулировки из банка (что адаптировано под JD – перечислить).
```

## Правила

- Адаптация = переформулировка и акценты, не выдумки (факты — `_common.md`).
- Key achievements — готовый resume-блок: полный список по проектам, copy-paste без правок. Не переписывать формулировки банка без необходимости адаптации под вакансию.
- Не сжимать опыт до неузнаваемости: если пользователь просил не упоминать X — соблюдать (см. master-cv → «Что НЕ писать»).
- В конце — честный список того, что под вакансию пришлось опустить.
