# Prompt: achievement bullets с цифрами

## Как выполняем в job-hunt

Подстановки: см. `_common.md`. Если просишь про конкретную роль – берём её; если нет – спрашиваем, какую из Experience разбираем. Роль, компания + индустрия и длительность берутся из Experience-блока роли в `data/profile/master-cv-{ru|en}.md`; текущие 3–5 bullets роли – оттуда же «как есть».

**Вход:** Experience-блок роли из `data/profile/master-cv-{ru|en}.md`, `data/profile/achievements.md`, `data/profile/experience-insights/` (+ точечно `data/profile/self-interview.md` по номеру вопроса)
**Выход:** переписанные bullets → в чат; после твоего подтверждения – в `data/profile/achievements.md` (и в Experience master-cv, если просишь). Мастер-CV без подтверждения не трогаем.
**Применение:** наполнение банка achievements (общий случай) и блок Key achievements в `resume-adapted.md`. В флоу 1 bullets **не переписываются заново**: берутся из готового банка (и Experience) как есть; правка формулировки – только если нужна адаптация под вакансию (лексика JD, язык резюме). Отбор, объединение мелкого и пропуск незначительного под вакансию – в `tailor-resume.md` → «Фильтры значимости и трансформация». Блок Key achievements собирается полным списком по проектам – готовым к copy-paste в резюме.

## Шаги

1. Взять 3–5 текущих bullets роли «как есть».
2. Проверить каждый на наличие конкретной цифры.
3. **Есть цифры** → переписать в формате `[action verb] + [scope/scale] + [result with number] + [tool/method]`.
4. **Нет цифр** → сначала проверить `data/profile/experience-insights/` и интервью (`В<N>`): цифра может уже быть в ответе. Если её нет → задать ровно 3 вопроса, чтобы вытащить цифры из памяти. Направления вопросов (выбрать 3 самых подходящих):
   - масштаб: сколько клиентов/пользователей/сервисов/экранов/релизов затронуто?
   - до/после: что ускорилось/сократилось/выросло и на сколько (%, разы, часы, деньги)?
   - частота/объём: сколько в единицу времени (дней, деплоев, запросов, тикетов)?
5. Получил ответы → вернуться к шагу 3. Пользователь не знает цифру → честно «N/A», bullet переписывается без выдуманного числа (scope/scale вместо result).

## Фильтры и трансформация формулировок

Правила уровня одного bullet'а. В флоу 1 их применяет `tailor-resume.md` на этапе отбора в Key achievements; здесь – при переписывании bullets в банк и в Experience. Примеры до/после – в `tailor-resume.md` → «Фильтры значимости и трансформация».

- **Обобщай мелкое:** несколько мелких родственных задач одного проекта → один bullet, если это одно достижение. Все факты и все источники `В<N>` сохраняются; субъект действия и сила глагола не меняются. Разные проекты, разный субъект (я / команда) и разные результаты не объединять.
- **Impact:** bullet отвечает на «и что это дало бизнесу/команде?». Цифра в источнике → результат с числом; цифры нет → качественный результат из источника; ни того ни другого → scope/scale. Результат не выдумывать.
- **Senior-фокус:** при равной релевантности вперёд идут менторство и найм, внедрение процессов и quality gates, архитектурные решения и ownership, сложные интеграции и кросс-платформенная работа, работа с легаси и миграции.
- **Сильный глагол, но не сильнее источника:** использовал/участвовал → внедрял/реализовал → выстроил/настроил → возглавил/спроектировал/инициировал | used → implemented → built / set up → led / architected / spearheaded. Гиперболы запрещены: revolutionized, transformed, game-changing, «революция», «кардинально».
- **Терминология JD – лексика, а не факт:** scalability / масштабируемость, maintainability / поддерживаемость, performance tuning / оптимизация производительности, cross-functional / кросс-функциональное взаимодействие – только если термин есть в JD или подтверждён содержанием источника.
- **Пропуск незначительного:** задача без влияния и не относящаяся к вакансии → не включать; в `resume-adapted.md` перечислить в «Опущено под вакансию».
- **Язык:** EN-резюме – английские глаголы и термины, RU-резюме – русские; правила те же. Всегда «–» (en dash), никогда «—» (em dash).

## Правила

- Формат каждого bullet: `action verb` (past tense: led, built, cut, shipped...) + `scope/scale` + `result with number` + `tool/method`. Один bullet – одно достижение; мелкие родственные задачи одного проекта объединяются в одно достижение (см. «Фильтры и трансформация»).
- Fact fidelity: переформулировка ≠ переизобретение. Не менять субъект действия, силу глагола, scope, цифры и технологии. Нет цифры → честно N/A, не выдуманное число.
- Тон: factual. Запрещённые слова-заглушки: successfully, efficiently, effectively (и семейство: seamlessly, robustly, significantly без цифры).
- **Эталон качества** – стиль этого bullet использовать как образец: «led migration to GA4 across 40 B2B clients, reducing reporting time 60% using Mixpanel + custom dashboards».
