# Prompt: поиск вакансий

**Вход:** `profile/target-role.md` (+ `profile/master-cv-{ru|en}.md` для уточнения запросов).
**Выход:** список вакансий + строки в `vacancies/INDEX.md`.

## Шаги

1. Прочитать `profile/target-role.md`: роль, альтернативные названия, must-have ключевые слова, условия, источники.
2. Сформировать 3–5 поисковых запросов (роль + ключевые слова + локация/формат).
3. Искать по источникам из target-role: веб-поиск, карьерные страницы компаний из wishlist, агрегаторы. Для каждой вакансии фиксировать:
   - компания, роль, ссылка, источник, дата находки
   - локация/формат, вилка (если опубликована)
   - однострочное «почему подходит / сомнения»
4. Отфильтровать по must-have и «чего избегать» — не попавшие показать отдельным списком «на грани» с причиной.
5. Вывести список пользователю (таблица: компания / роль / ссылка / формат / краткий вердикт).
6. Добавить новые вакансии в `vacancies/INDEX.md` со статусом `new`, не дублируя уже имеющиеся ссылки.

## Формат вывода

| Компания | Роль | Ссылка | Формат | Вилка | Вердикт |
|---|---|---|---|---|---|

Итог: сколько найдено, сколько в «на грани», что стоит проверить руками.

## Правила

- Не выдумывать ссылки и вилки. Нет данных — ставить «—».
- Дубликаты (та же компания+роль) не добавлять.
- **Лимиты веба** (`_common.md` → «Веб: оркестрация research и экономия токенов»): из SERP брать заголовок/сниппет/ссылку; JD открывать **только у короткого списка** (3–5 после фильтра) или уже когда пользователь выбрал вакансию для флоу 1. Не раскрывать все найденные карточки.
