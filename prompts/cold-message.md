# Prompt: cold message рекрутеру / hiring manager (4 строки)

## Как выполняем в job-hunt

Подстановки: см. `_common.md`; наблюдения по человеку берутся из `people.md` (собираются перед драфтом, шаг 0).

**Вход:** `people.md` (с наблюдениями), `vacancy.md`, `resume-adapted.md`, `data/profile/achievements.md`, `data/profile/experience-insights/` (+ точечно `data/profile/self-interview.md` по номеру вопроса)
**Выход:** основной текст `drafts/recruiter.md` и `drafts/lead.md` (application-режим) – ровно 4 строки
**Режим:** A. В network-режиме (`network-recruiter.md` / `network-lead.md`) – тот же каркас, но строка 3: почему пишу сейчас без открытой роли (интерес к команде/продукту).

## Шаги

0. **Наблюдения:** взять about + 3 последних поста человека; выбрать одну конкретную деталь (пост, проект, тема доклада) для строки 1.
1. Строка 1 – Hook (Зацепка): Искреннее конкретное наблюдение о профиле или посте рекрутера. Без лести, просто как живой человек. Никаких «hope this finds you well».
2. Строка 2 – Опыт в одно предложение: Коротко, какой стек и какой главный результат (из банка или подтверждённый факт из `experience-insights/`, с цифрой), который важен для их вакансии. Смысл факта не усиливать.
3. Строка 3 – Цель: Почему пишу именно им (интересен продукт/технологии) и именно сейчас и что именно хочу (роль / фидбек / разговор).
4. Строка 4 – Call to Action (CTA): Легкий вопрос, на который несложно ответить (не проси сразу собеседование): просьба о feedback | вопрос, на который легко ответить.


## Проверка перед выдачей

- Ровно 4 строки – DM на телефоне должен читаться с одного взгляда.
- Строка 1 уникальна для этого человека: подставить другому человеку нельзя.
- Запрещённых слов нет (grep: opportunity, excited, passionate).
- Тон: дружелюбный, не sales; achievement с цифрой – только из банка или подтверждённого факта интервью.
- Fact fidelity: новые факты запрещены, смысл не искажать – только формулировка (`_common.md`).

## Правила

- Пиши так, как пишут люди в мессенджерах: лаконично и по делу.
- Без комплиментов-заглушек и продающего тона; наблюдение – настоящее, из его контента.
- Постов нет → деталь из about или его работы; совсем нечего зацепить → спросить пользователя, чем персонализировать, без фальшивого «узнал о вашей компании».
- Наблюдения не собраны → драфт не писать.
