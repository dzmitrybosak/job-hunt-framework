# Prompt: закрытие пробелов (топ-3) под вакансию

## Как выполняем в job-hunt

Подстановки: см. `_common.md`. Работает в связке с `gap-analysis.md`: таблица требований и Match % считаются там, здесь — глубокая работа с топ-3 пробелами.

**Вход:** `vacancy.md`, `gap-analysis.md`, `data/profile/master-cv-{ru|en}.md`, `data/profile/achievements.md`, `data/profile/experience-insights/` (+ точечно `data/profile/self-interview.md` по номеру вопроса)
**Выход:** `gap-close.md` в папке вакансии
**Режим:** A (флоу 1). В network-режиме не применяется — JD нет; только по явному запросу.

## Шаги

1. Взять из `gap-analysis.md` кандидатов в пробелы и выбрать **топ-3** пробела между профилем и идеальным кандидатом по этому JD – по болезненности для работодателя (приоритет: must-have ❌ → must-have ⚠️ → nice-to-have ❌). Важность требования важнее размера гэпа.
2. Для каждого пробела закрыть его **только реальным опытом** из master-cv/achievements/`experience-insights/` (истории и мосты): переформулировать, переставить акценты, поднять на поверхность то, что было в конце резюме. Никаких новых технологий, ролей, компаний и цифр. Смысл факта не усиливать: «участвовал» не становится «руководил», «использовал» – «внедрил». Факт из интервью помечать `В<N>`.
3. Что реально не закрывается — честно сказать и предложить компенсацию: что подтянуть быстро, какую смежную историю рассказать, как отвечать на интервью, что сделать до отклика.

## Формат `gap-close.md`

```md
# Gap close — <Company> / <Role>
Дата:
На основе: gap-analysis от <дата>

## Пробел 1: <требование из JD>
<3–4 предложения: в чём пробел и чем из имеющегося опыта его закрываем>
- <готовый bullet point для CV>
- <готовый bullet point для CV>

## Пробел 2: ...

## Пробел 3: ...

## Что не закрывается (честно)
- <пробел> → компенсация: <что делать>
```

## Правила

- Каждый bullet — готовая строка для CV, но правдивая уже сегодня: её можно вставить без последующих «уточнений».
- Fact fidelity: новые факты запрещены, смысл не искажать – только формулировка (`_common.md`). Если переформулировка усиливает вклад или scope – вернуть исходник.
- Материала нет → сразу «не закрывается» + компенсация; не растягивать слабый опыт в ложь.
- В HTML-отчёте каждому пробелу — своя copy-кнопка.
