# Prompt: init — инициализация профиля кандидата

Команда `init-job-hunt`. Выполняется **один раз** (или повторно для обновления профиля). Цель — заполнить `data/profile/` данными пользователя.

**Выход:** заполненные `data/profile/master-cv-{ru|en}.md`, `data/profile/target-role.md`, `data/profile/achievements.md`, `data/profile/links.md`, актуальный `data/profile/experience-insights/` + короткая сводка «что заполнено, чего не хватает».

## Шаги

0. **Начни диалог сам.** Прочитай `data/profile/*.md`, определи пустые/неполные блоки и начни интервью: **первое сообщение агента — приветствие + 2–4 конкретных вопроса по недостающим блокам**, а не описание процесса. Пустые секции-заглушки и поля «...» = не заполнено: если CV ещё не приходило — профиль пустой, спроси CV первым. Уже заполненное не переспрашивай; если пусто почти всё — иди по порядку ниже. Это диалог, не анкета: по ответам задавай следующие вопросы. Инициатива — на агенте.
1. **Master CV.** Попросить прислать CV любым способом: текстом в чат, файлом или ссылкой (Google Docs — извлекать по skill `cv-vacancy-tailor`, PDF/файл — прочитать). CV хранится в двух языковых версиях: `data/profile/master-cv-ru.md` (русский) и `data/profile/master-cv-en.md` (английский) – разложить по версиям (Header, Summary, Core skills, Experience с датами и стеком, Education, Languages, проекты). Если прислали одну языковую версию – спросить про вторую; не переводить самому без подтверждения. Не сокращать факты. Общие неязыковые факты (локация, пет-проекты, «Что НЕ писать») – в `data/profile/master-cv.md`.
2. **Ссылки** (`links.md`): LinkedIn (personal URL), GitHub, блог/портфолио, email для вакансий, Telegram. Спросить, как подписываться в переписке (имя на английском).
3. **Желаемые роли** (`target-role.md`): задать вопросы по очереди (не анкетой на 20 пунктов):
   - какие роли и уровни ищешь (1–3, по приоритету, с альтернативными названиями для поиска)?
   - какие 3–5 технологий must-have?
   - формат: remote / hybrid / onsite, страны, часовые пояса?
   - минимальная вилка, тип занятости?
   - какие индустрии интересны / не интересны, размер компании?
   - что важно в компании, чего избегать?
   - wishlist компаний и источники поиска?
4. **Достижения** (`achievements.md`): из CV взять все места с цифрами; по остальным — техника 3 вопросов из `achievement-bullets.md` (масштаб / до-после / частота-объём), чтобы вытащить цифры из памяти. Оформить записи A1, A2... в формате Ситуация/Действие/Результат/Стек.
4a. **Self-interview** (`data/profile/self-interview.md`): файл только для чтения, никогда не изменять. Если он есть, проверить актуальность `data/profile/experience-insights/` (индекс, истории, evidence map, мосты): отсутствует или старше интервью – выполнить `prompts/self-interview.md` и обновить только производные файлы. Ответы из интервью использовать как источник фактов наравне с CV, с пометкой `В<N>`; новые факты не добавлять, смысл не искажать.
5. **Проверка:** пройтись по секциям обеих версий master-cv — отметить пустые; свести итог: что заполнено, что стоит дописать. Показать пользователю и попросить подтвердить. Пользователь не должен вытягивать вопросы из агента — доводи до заполненного профиля сам.

## Правила

- Не переписывать CV «красивее» — структурировать, не менять смысл и цифры (факты — `_common.md`).
- Формат achievements — по `achievement-bullets.md` (verb + scope + result с цифрой + tool).
- После init не трогать `data/profile/` без явного запроса пользователя.
